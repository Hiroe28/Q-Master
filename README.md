# Q-Master

**3週間で完全習得を目指す**、科学的な復習スケジュールに基づいたクイズ学習アプリです。

## このアプリの特徴

### 効率的な学習
- **「忘れる前に復習」** を自動でスケジューリング
- 5回連続正解で完全習得（約3週間で達成可能）
- 間違えても1段階戻るだけ（最初からやり直しにはなりません）

### 多彩な学習モード
- **4択クイズ** - 選択肢から正解を選ぶ
- **タイピング** - 答えを直接入力（英単語学習に最適）
- **フラッシュカード** - 暗記カード形式で学習

### AIで問題を自動生成
- テーマを入力するだけで問題を自動作成
- 教科書やノートの写真から問題を生成することも可能

### 安心のプライバシー設計
- **すべてのデータはあなたのブラウザ内にのみ保存**されます
- サーバーへのデータ送信は一切ありません
- APIキーもブラウザ内に保存され、外部には送信されません

## 使い方

### 1. 問題を追加する

#### 手動で追加
1. 画面下の「管理」タブを開く
2. 「+ 問題を追加」ボタンをクリック
3. 問題文、選択肢、正解、解説を入力
4. 「保存」をクリック

#### AIで自動生成（OpenAI APIキーが必要）
1. 「管理」→「AI生成」タブを開く
2. OpenAI APIキーを入力（初回のみ、下記参照）
3. 学習したいテーマを入力（例：「日本の歴史 江戸時代」）
4. 「問題を生成」をクリック
5. 生成された問題を確認し、追加したいものを選択
6. 「選択した問題を追加」をクリック

### 2. 学習する

1. 画面下の「学習」タブを開く
2. 「今日の学習を開始」をクリック
3. 問題に答えていく

アプリが自動的に「今日復習すべき問題」と「新しい問題」をバランスよく出題します。

### 3. 進捗を確認する

「管理」→「問題一覧」で各問題の達成率（%）を確認できます。
- 問題ごとの進捗バーで習得度が一目でわかります
- どのセット（グループ）に属しているかも表示されます

## OpenAI APIキーについて

AI問題生成機能を使うには、OpenAI APIキーが必要です。

### APIキーの取得方法

1. [OpenAI公式サイト](https://platform.openai.com/) にアクセス
2. アカウントを作成またはログイン
3. 右上のメニューから「API keys」を選択
4. 「Create new secret key」をクリック
5. 表示されたキー（`sk-...`で始まる文字列）をコピー

詳しくは [OpenAI APIキーの取得方法（公式ドキュメント）](https://platform.openai.com/docs/quickstart) を参照してください。

### APIキーの安全性について

- **APIキーはあなたのブラウザ内にのみ保存**されます
- 当アプリのサーバーには送信されません
- APIキーはOpenAIへの問題生成リクエスト時にのみ使用されます
- 他の人があなたのAPIキーを見ることはできません

### 料金について

- OpenAI APIは従量課金制です
- 問題生成には GPT-5-mini モデルを使用しており、**非常に低コスト**です
- 目安：100問生成しても数円〜数十円程度

## 学習進捗（達成率）の仕組み

問題一覧に表示される**達成率（%）**は、科学的な間隔反復に基づいて計算されます。

### 復習間隔の変化

| 状況 | 次の復習まで | 達成率 |
|------|-------------|--------|
| 初回正解 | 1日後 | 約5% |
| 2回連続正解 | 3日後 | 約14% |
| 3回連続正解 | 1週間後 | 約33% |
| 4回連続正解 | 2週間後 | 約67% |
| 5回連続正解 | 3週間後 | **100%（完全習得）** |
| 不正解 | 1段階戻る | 半分に減少 |

**ポイント:**
- **5回連続正解**で完全習得に到達
- 間違えても**1段階戻るだけ**（例：67%で不正解 → 33%に戻る）
- 完全習得した問題は復習対象から外れます

## データのバックアップ

「管理」→「データ」タブから、学習データをバックアップ・復元できます。

- **エクスポート**: すべての問題と学習履歴をZIPファイルで保存
- **インポート**: 保存したZIPファイルから復元

機種変更やブラウザ変更時にご利用ください。
